# SM-110: The association records are never given back

- Original: `CAssociationReputationMgr::SelectAssociation` (0x434910), SR_ShardManager
- Rewrite: `CAssociationReputationMgr::SelectAssociation` in `SilkroadOnline/Server/ShardManager/AssociationReputation.cpp`
- Severity: minor

## What the original does

The _AssociationReputation row is selected into a local record list; the function returns the
first record and destroys the list without handing the records back to the table.

## Effect

The four records of LoadAssociations stay allocated for the life of the process (one load per
start, so the loss is small).

## Fix

Copy the reputation and give the records back with CDBObjectList_DetachAndClear.
