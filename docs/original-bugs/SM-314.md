# SM-314: Standard shard schedules copy their parameter text with a 256-byte limit

- Original: `AQ_ScheduleChangeStandardShard::CopyRecord` (0x474550), SR_ShardManager
- Rewrite: `AQ_CopyStandardScheduleRow` in
  `SilkroadOnline/Server/ShardManager/AQScheduleJobs.cpp`
- Severity: major

## What the original does

After `_InsertSchedule_AllShard` succeeded, the schedule row is copied for the schedule
manager. The name and the parameter text are copied with `strcpy_s(dst, 0x100, src)`; the
parameter buffer of the row is 2000 bytes (`sScheduleRow::Copy` uses 0x7D0 for it).

## Effect

A schedule of the standard shard whose parameter text has 256 or more characters is inserted
into `_Schedule`, then `strcpy_s` fails and calls the invalid parameter handler, which ends the
process unless the application installed its own handler. The rewrite does the same.

## Fix

Copy the parameter text with the size of its buffer (0x7D0), like `sScheduleRow::Copy`.
