# SM-135: Completion and reward message leaks on the error returns

- Original: `CServerEventMgr::ProcessingDelayJob_CompletionAndReward` (0x67e280), SR_ShardManager
- Rewrite: `CServerEventMgr::ProcessingDelayJob_CompletionAndReward` in `SilkroadOnline/Server/ShardManager/ServerEventMgr.cpp`
- Severity: minor (leak)

## What the original does

The function allocates the 0x34F2 message and writes its head before it checks the user of a
user reward, the reward target and the reference of the event. When the user is not online, the
target is 3 or 4, or the event has no reference, it logs, asserts and returns FALSE without
freeing or sending the message.

## Effect

One message of the network engine pool is lost per failed reward. The rewrite loses it the same
way.

## Fix

Check the user, the target and the reference before the message is allocated, or free it on
these paths.
