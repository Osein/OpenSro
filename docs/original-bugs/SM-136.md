# SM-136: The remaining reward time update logs a failed delete

- Original: `CServerEventReward::UpdateRemainTime` (0x6816a0), SR_ShardManager
- Rewrite: `CServerEventReward::PostJob` in `SilkroadOnline/Server/ShardManager/ServerEvent.cpp`
- Severity: cosmetic

## What the original does

When no AQ_ServerEvent job can be allocated for the update (kind 4) of the remaining reward
time, the function logs "Failed to DeleteServerEventReward[%d] ServerEventID[%d]", the text of
RequestDelete.

## Effect

The log reports a delete that was never attempted. The rewrite logs the same text.

## Fix

Log "Failed to UpdateServerEventReward[%d] ServerEventID[%d]".
