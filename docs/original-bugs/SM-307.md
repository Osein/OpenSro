# SM-307: The statement jobs use their statement as a format string

- Original: `AQ_Statistics::vf06` (0x481080), `AQ_TrijobRanking::vf06` (0x482840),
  `AQ_UserDataSelector::vf06` (0x483c90), `CCharDataSelector::vf03` (0x487dd0),
  `CCharDataEditor::vf03` (0x48bc80), SR_ShardManager
- Rewrite: `CAQStatementJobT::RunStatement` in
  `SilkroadOnline/Server/ShardManager/AQStatementJobs.cpp`, `CCharDataSelector::Execute` and
  `CCharDataEditor::Execute` in `SilkroadOnline/Server/ShardManager/CharDataEditor.cpp`
- Severity: minor

## What the original does

The statement is formatted once from the console request (names, dates, counts) and then
passed as the format argument of `CDBQuery::ExecuteFormat`, without arguments.

## Effect

A `%` in a name or date of the request is interpreted a second time as a format specifier:
the statement changes, and `%s` / `%n` read or write stack data. The rewrite does the same.

## Fix

Call `ExecuteFormat("%s", text)` or copy the text into the query and call `Execute`.
