# SM-301: A character data request with an unknown mode calls through a NULL editor

- Original: `AQ_CharDataEditor::vf09` (0x466630), SR_ShardManager
- Rewrite: `AQ_CharDataEditor::ReadRequest` in `SilkroadOnline/Server/ShardManager/AdminQueryJobs.cpp`
- Severity: major (a console request crashes the shard manager)

## What the original does

The mode byte selects the editor: 0 creates a `CCharDataSelector`, 1 a `CCharDataEditor`. Any
other value throws, the handler leaves the editor NULL, the code asserts and then calls the
editor's request reader (slot 1) through the NULL pointer.

## Effect

An SMC request with a mode other than 0 or 1 makes the shard manager fault. The rewrite does
the same.

## Fix

Set result 11 and return false when no editor was created.
