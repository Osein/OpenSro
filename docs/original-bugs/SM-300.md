# SM-300: The association reputation statement is used as a format string

- Original: `AQ_AssociationReputation::vf06` (0x465690), SR_ShardManager
- Rewrite: `AQ_AssociationReputation::Execute` in `SilkroadOnline/Server/ShardManager/AdminQueryJobs.cpp`
- Severity: minor

## What the original does

The job passes its statement text directly as the format argument of
`CDBQuery::ExecuteFormat`, without arguments.

## Effect

A `%` in the statement (for example in a `LIKE '%...%'` pattern) is interpreted as a format
specifier: the text sent to the database changes, and `%s` / `%n` read stack data. The rewrite
does the same.

## Fix

Call `ExecuteFormat("%s", text)` or copy the text into the query and call `Execute`.
