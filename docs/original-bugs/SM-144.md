# SM-144: SyncData leaves the stream writer bound on its early returns

- Original: `CServerEventMgr::SyncData` (0x67dc20), `CServerEventMgr::SendRewardProgressSync` (0x67ded0), SR_ShardManager
- Rewrite: `CServerEventMgr::SyncData`, `CServerEventMgr::SendRewardProgressSync` in `SilkroadOnline/Server/ShardManager/ServerEventMgr.cpp`
- Severity: minor

## What the original does

Both functions bind the byte stream at +0x6C to the buffer at +0x58 before the loop. On a NULL
event, a NULL reference or a NULL reward they clear the buffer positions, assert and return
without unbinding the stream (its buffer pointer and the owner at +0x80 stay set).

## Effect

The destructor of the manager asserts on the bound stream. The next call binds it again, so the
stream itself keeps working. The rewrite returns the same way.

## Fix

Unbind the stream before returning.
