# SM-341: Item edits put unchecked names from the item row into the statement

- Original: `CCharDataEditor::ReadRequest` (0x4883e0, edit types 9, 10, 11, 19), SR_ShardManager
- Rewrite: `ReadItemEdit` in `SilkroadOnline/Server/ShardManager/CharDataEditor.cpp`
- Severity: major

## What the original does

An item edit carries an owner name in the message and, for adding and editing, a 0x143-byte
item row with its own owner name and creator name. The name rule and the in-game check are
applied to the message name only. The `_SMC_ADD_ITEM` / `_SMC_EDIT_ITEM` statements are built
from the row: its owner name (checked with the name rule only for the character and guild
chests) and its creator name (never checked) are put between quotes into the SQL text.

## Effect

The inventory and avatar inventory edits can change the items of another, online character
than the one checked, and a quote in the creator name (or the unchecked owner name) breaks or
extends the statement. The rewrite does the same.

## Fix

Check both names of the row with the name rule, require the row owner to match the message
name, and pass the values as statement parameters.
