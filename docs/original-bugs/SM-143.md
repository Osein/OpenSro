# SM-143: AllocNewServerEventReward leaks on its failures

- Original: `CServerEventMgr::AllocNewServerEventReward` (0x681430), SR_ShardManager
- Rewrite: `CServerEventMgr::AllocNewServerEventReward` in `SilkroadOnline/Server/ShardManager/ServerEventMgr.cpp`
- Severity: minor (leak)

## What the original does

After CreateRecord the function returns NULL (assert) when no reward object can be taken from
the pool, the reference reward is missing or Link fails, without freeing the record or the
reward object.

## Effect

One record and possibly one pooled reward leak per failure. The rewrite leaks the same way.

## Fix

Free the record and release the reward on the failure paths.
