# SM-141: A missing event is handed to the end log as NULL

- Original: `CServerEventMgr::ProcessingDelayJob_CheckEndServerEvent` (0x67e610), SR_ShardManager
- Rewrite: `CServerEventMgr::ProcessingDelayJob_CheckEndServerEvent` in `SilkroadOnline/Server/ShardManager/ServerEventMgr.cpp`
- Severity: minor

## What the original does

When the event of the job is not in the map the function logs "Why not found ServerEvent" and
still calls ServerEventLog_LogCompletion with the NULL event, then DeleteServerEvent.

## Effect

The log helper gets a NULL event. The rewrite passes NULL the same way.

## Fix

Return after the log when the event is missing.
