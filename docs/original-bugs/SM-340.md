# SM-340: A timed job edit with an unknown operation runs an uninitialised statement

- Original: `CCharDataEditor::ReadRequest` (0x4883e0, edit type 12), SR_ShardManager
- Rewrite: `ReadTimedJob` / `CCharDataEditor::ReadRequest` in
  `SilkroadOnline/Server/ShardManager/CharDataEditor.cpp`
- Severity: major

## What the original does

The statement buffer (0xC00 bytes on the stack) is not initialised; only the description and
the log buffers are. The timed job edit (type 12) reads an operation byte and formats its
statement only for operation 1 (deletion). Any other operation still returns success, so the
request reader copies the untouched stack buffer into the statement and Execute runs it.

## Effect

A console request with a timed job operation other than 1 executes whatever text was left on
the stack (usually garbage that fails, possibly an earlier statement). The rewrite does the
same.

## Fix

Fail the request (invalid message) for operations other than 1, or initialise the statement
buffer to an empty string.
