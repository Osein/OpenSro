# SM-133: The "WorkingStateWhenServiceStart is not exist" log passes the string object for %s

- Original: `CShard_ScheduleManager::OnServiceStartSchedule` (0x663690), SR_ShardManager
- Rewrite: `CShard_ScheduleManager::OnServiceStartSchedule` in `SilkroadOnline/Server/ShardManager/ShardSchedule.cpp`
- Severity: minor (only when a define has no registered job)

## What the original does

The define name is copied by value (all 28 bytes of the std::string) into the variable
arguments of LogPrintf, so %s takes the first dword of the object (the allocator slot) as the
text pointer.

## Effect

The line prints garbage or the log formatter faults on an invalid pointer. The rewrite pushes
the same 28 bytes.

## Fix

Pass strDefine.c_str().
