# SM-311: Skill page looks reference skills up with lower_bound

- Original: `AQ_CharDataSelector::WriteSkillsAndMasteries` (0x46a430), SR_ShardManager
- Rewrite: `AQ_CharDataSelector_WriteSkills` in
  `SilkroadOnline/Server/ShardManager/AQCharDataQueries.cpp`
- Severity: minor

## What the original does

For every skill and mastery of the character the reference row is taken from
`std::map::lower_bound(ID)` without comparing the key; at the end of the map the row pointer
is NULL and is read anyway.

## Effect

A skill or mastery ID that is not in the reference data shows the level of the next ID; one
above the largest ID reads through a NULL pointer and crashes the shard manager. The rewrite
does the same.

## Fix

Use `find` and write 0 when the ID is unknown.
