# SM-111: Unknown temple codes count as Anubis

- Original: `AssocRep_TempleIndexFromCode` (0x434b70), SR_ShardManager
- Rewrite: `CAssociationReputationMgr::TempleIndexFromCode` in `SilkroadOnline/Server/ShardManager/AssociationReputation.cpp`
- Severity: minor

## What the original does

"TEMPLE_ANUBIS" gives 0, "TEMPLE_HAROERIS" gives 1, and every other code also gives 0.

## Effect

Points a game server sends (0x74DB) for an unknown association code are added to the Anubis
temple, and a query (0x7CDC) for one answers the Anubis points.

## Fix

Return -1 for unknown codes; the add and get helpers already ignore other indices.
