# SM-114: The missing member check of the siege authority never fires

- Original: `CGuild::SetMemberSiegeAuthority` (0x437cb0), SR_ShardManager
- Rewrite: `Guild_SetMemberSiegeAuthority` in `SilkroadOnline/Server/ShardManager/GuildSiegeAuthority.cpp`
- Severity: minor

## What the original does

Guild_GetMemberSiegeAuthority returns a BYTE (0xFF without member, after an assert); the caller
zero-extends it and compares with -1, which is never equal, so error 3 is never returned.

## Effect

A missing member asserts in Guild_GetMemberSiegeAuthority and its 0xFF authority runs through
the checks: a removal reaches the member lookup and answers 0x4C1D, a grant answers 0x4C5A
("already has one") instead of a member error.

## Fix

Compare the byte with 0xFF.
