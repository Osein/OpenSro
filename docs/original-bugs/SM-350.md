# SM-350: Some magic options replace the item description built so far

- Original: `Item_FormatDescription` (0x469240), SR_ShardManager
- Rewrite: `Item_FormatDescription` / `FormatMagicOption` in
  `SilkroadOnline/Server/ShardManager/AQCharDataQueries.cpp`
- Severity: minor

## What the original does

The magic option part of an equipment description is built in one 1024-byte buffer: it starts
with `[`, every option is added with a `"%s, <name> +%d"` format that passes the buffer itself
as `%s`, and `%s]` closes it. The formats of the bless options (`atha`, `ape`, `rep`, `luck`,
`solid`), of `unreparable` and of `reinforce` have no `%s`, so they overwrite the buffer.

## Effect

For an item with one of these options the console shows only that option and the ones after
it; the opening `[` and every earlier option are lost. The rewrite does the same.

## Fix

Prefix these formats with `%s, ` like the other options.
