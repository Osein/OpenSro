# SM-353: LoadPetItem frees the pet list through a NULL table

- Original: `AQ_CharDataSelector::LoadPetItem` (0x46c930), SR_ShardManager
- Rewrite: `AQ_CharDataSelector::LoadPetItem` in
  `SilkroadOnline/Server/ShardManager/AQCharDataQueries.cpp`
- Severity: minor (only reached when the shard DB has no `_CharCOS` table)

## What the original does

When the `_CharCOS` table (index 7) is missing from the shard DB, `LoadPetItem` asserts and
then hands the pet list to `CDBObjectList_DetachAndClear` with that NULL table.

## Effect

Every record of the list is "freed" through a NULL table object, which crashes as soon as the
list is not empty. The rewrite does the same (`DB_FreeRecordList(pCOS, NULL)`).

## Fix

Return without touching the list (the caller frees it through the right table).
