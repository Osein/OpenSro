# SM-138: A failed load frees records that loaded events already hold

- Original: `CServerEventMgr::LoadServerEvents` (0x67f020), `CServerEventMgr::LoadServerEventRewards` (0x67f350), SR_ShardManager
- Rewrite: `CServerEventMgr::LoadServerEvents`, `CServerEventMgr::LoadServerEventRewards` in `SilkroadOnline/Server/ShardManager/ServerEventMgr.cpp`
- Severity: major (after a failed start)

## What the original does

When one record of the list cannot be turned into an event or reward (allocation, attach,
insert or delayed job failure), the function hands every record of the query list back to the
table (CDBObjectList_DetachAndClear 0x40a7e0), including the records it attached before to
events and rewards that are in the manager maps and in the delayed job heap.

## Effect

The registered events and rewards point at freed records. The rewrite frees the same records.

## Fix

Free only the records that were not handed to an event or reward.
