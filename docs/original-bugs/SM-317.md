# SM-317: The rent information query leaks its records

- Original: `AQ_CharDataSelector::QueryItemExtra` (0x46ce40), SR_ShardManager
- Rewrite: `AQ_CharDataSelector::QueryItemExtra` in
  `SilkroadOnline/Server/ShardManager/AQCharDataQueries.cpp`
- Severity: minor

## What the original does

`AQ_CharDataSelector::LoadByItemDBID` selects the `_RentItemInfo` rows of the item serial into
a record list. After the first row is written into the answer, the list is destroyed as a
plain `std::list`; the records are only handed back to the table when the select fails.

## Effect

Every successful rent information query of the console leaks the selected record objects.
The rewrite does the same.

## Fix

Free the list through the `_RentItemInfo` table (`CDBObjectList_DetachAndClear`) after writing
the answer, like the item detail query does.
