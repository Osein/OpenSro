# SM-132: DeleteInstance destroys the running job copy as IScheduleJob

- Original: `IShard_ScheduleJob::DeleteInstance` (0x664980, slot 3 of every shard job), SR_ShardManager
- Rewrite: `IShard_ScheduleJob::DeleteInstance` in `SilkroadOnline/Server/ShardManager/ShardScheduleJob.cpp`
- Severity: minor (memory)

## What the original does

It runs the destructor of `NewSchedule::IScheduleJob` (not virtual) on the copy kept in
m_pInstance and frees it.

## Effect

Members of the derived job are never destroyed: the open-time list of the temple gate jobs
(its head node and any entries left) leaks every time a copy is deleted. The rewrite deletes
through the same non-virtual base.

## Fix

Give IScheduleJob a virtual destructor.
