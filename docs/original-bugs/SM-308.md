# SM-308: Statement jobs put console strings into SQL unchecked

- Original: `AQ_Statistics::vf09` (0x480a70), `AQ_UserDataSelector::vf09` (0x483a10),
  SR_ShardManager
- Rewrite: `AQ_Statistics::ReadRequest` and `AQ_UserDataSelector::ReadRequest` in
  `SilkroadOnline/Server/ShardManager/AQStatementJobs.cpp`
- Severity: major

## What the original does

The character names, account names and date strings of the request are formatted into the
statement between quotes. Unlike the other console jobs, neither job calls
`CShardDB::CheckSqlInjection` or checks the name.

## Effect

A quote in a request string ends the literal: anyone who can send console requests runs
arbitrary SQL on the shard database. The rewrite does the same.

## Fix

Check the strings with `CShardDB::CheckSqlInjection` (or bind them as parameters) and reject
the request with result 5 like `AQ_CharDataSelector`.
