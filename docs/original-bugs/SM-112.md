# SM-112: A Haroeris draw has no winner

- Original: `CAssociationReputationMgr::DecideTempleWinner` (0x434d60), SR_ShardManager
- Rewrite: `CAssociationReputationMgr::DecideTempleWinner` in `SilkroadOnline/Server/ShardManager/AssociationReputation.cpp`
- Severity: minor

## What the original does

With equal points the Anubis temple gets winner 3 (draw), the Haroeris temple gets 0, the value
of "not decided".

## Effect

The temple gate job of Haroeris and Seth sends winner 0 after a draw where the Anubis gate sends
3, so the game servers treat the two draws differently.

## Fix

Set 3 for a Haroeris draw as well.
