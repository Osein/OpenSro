# SM-139: A recycled CServerEvent cannot be attached again

- Original: `CServerEvent::ResetAndDetach` (0x678c10), `CServerEvent::Attach` (0x678bd0), SR_ShardManager
- Rewrite: `CServerEvent::Attach` in `SilkroadOnline/Server/ShardManager/ServerEvent.cpp`
- Severity: major

## What the original does

ResetAndDetach clears the reference (+8) and the synced values but not the record pointer (+4).
Attach refuses (assert, FALSE) an object whose record pointer is set.

## Effect

Once an event has ended and its object went back to the pool, the pool hands the object out
again with the old record pointer and Attach fails: loading or registering a later event logs
"Failed to initialize ServerEvent" or fails to append the wait-register job. The rewrite keeps
the pointer the same way.

## Fix

Set m_pRecord to NULL in ResetAndDetach.
