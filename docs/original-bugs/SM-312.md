# SM-312: The unknown server event type log misses an argument

- Original: `AQ_ServerEvent::vf06` (0x47aad0), SR_ShardManager
- Rewrite: `AQ_ServerEvent::Execute` in `SilkroadOnline/Server/ShardManager/AQServerEvent.cpp`
- Severity: minor

## What the original does

For an unknown event type the job logs
`"Not supported DoWork AQ_ServerEventType[%d]!!!. ServerEventID[%d]"` with only the server
event ID as argument (shown as the type); the second `%d` reads whatever is on the stack.

## Effect

The log line shows the event ID as type and a garbage value as event ID. The rewrite does the
same.

## Fix

Pass the event type and the event ID.
